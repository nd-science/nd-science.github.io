# Реестр ассетов

- `shared` — подтверждённые материалы, общие для двух сайтов.
- `wellness` — исходники и утверждённые материалы wellness-сайта.
- `science` — исходники и утверждённые материалы научного сайта.

Файлы из `docs/sources/screenshots` являются референсами и не предназначены для публичной сборки. `KompasIMG` остаётся отдельным legacy-каталогом.
