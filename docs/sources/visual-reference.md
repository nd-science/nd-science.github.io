# Визуальный референс wellness-сайта

Семь скриншотов показывают ранний черновик сайта. Они используются только как композиционный ориентир и не считаются утверждённым дизайном или проверенным контентом.

## Наблюдаемая структура

1. Hero с крупным заголовком о дыхании, соматике и нейроинтеграции.
2. Блок «Для кого подходит» с четырьмя карточками состояний.
3. Блок методов: дыхание, соматика, нейроинтеграция.
4. Два формата работы: 30-дневная программа и индивидуальные сессии.
5. Блок доверия с научным, безопасным и индивидуальным позиционированием.
6. Карточки полезных материалов.
7. Финальный CTA и футер.

## Решение для нового каркаса

- Сохранить спокойную подачу, крупную редакционную типографику, светлый фон и зелёный акцент.
- Не переносить неподтверждённые обещания и целевую аудиторию «женщины 23–50 лет» до ответа Наталии.
- Не фиксировать 30-дневную программу как реальный продукт: из поздних уточнений основной продукт — индивидуальное сопровождение.
- Не использовать исходную фотографию до подтверждения происхождения и права публикации.

Файлы находятся в `docs/sources/screenshots/` и названы по смыслу блоков.
