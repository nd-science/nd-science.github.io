# Локальный прототип вкладок

Прототип не связан с production-приложениями Astro и не предназначен для публикации.

## Запуск

Из каталога `workspace-tabs`:

```powershell
npx --yes http-server . -p 4177 -c-1
```

Два независимых входа:

- Wellness RU: `http://127.0.0.1:4177/wellness/ru/`;
- Science RU: `http://127.0.0.1:4177/science/ru/`.

Корневой `index.html` — только технический экран запуска и не является общей главной страницей.

## Устройство

- Wellness и Science находятся в разных корневых каталогах и не ссылаются друг на друга.
- Каждый пункт навигации внутри сайта ведёт на отдельный HTML-файл.
- `prototype.js` содержит только демонстрационные RU/EN-данные с явными статусами проверки.
- `prototype.css` задаёт общую оболочку и две темы.
- В прототипе нет форм, внешних запросов, аналитики, календаря и оплаты.
