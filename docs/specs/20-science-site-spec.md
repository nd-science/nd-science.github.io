## 1. Цель сайта

Science-сайт представляет Наталию как исследователя профессионального образования и обучения взрослых, Dr. phil., кандидата экономических наук, преподавателя и разработчика образовательных программ. Он объединяет научную биографию, публикации, проекты, выступления, образовательную экспертизу и предложения для организаций.

Сайт должен позволить посетителю:

1. Понять исследовательскую специализацию Наталии.
2. Увидеть степени, хронологию и профессиональные идентификаторы.
3. Найти диссертацию, ключевые публикации и выступления.
4. Оценить опыт разработки образовательных программ и исследований.
5. Направить запрос на сотрудничество, выступление, исследовательский или образовательный проект.

## 6. Пользовательские сценарии

### Исследователь

Поиск или DOI → публикация → профиль автора → исследования → контакт для сотрудничества.

### Университет или научная сеть

Главная → исследования → диссертация или проекты → биография → запрос на совместный проект.

### Образовательная организация

Главная → образование → проекты → экспертные услуги → форма брифа.

### Организатор события

Главная → конференции → темы → краткая биография → приглашение на выступление.

### Посетитель Wellness

Science → верхняя вкладка Wellness → отдельный сайт практики. Психологическая заявка не отправляется через Science.

## 9. Библиография и метрики

Каждая запись `Publication` содержит: `id`, RU/EN-title, authors, Natalia name variant, year, output type, venue, volume/issue/pages, DOI, primary URL, language, abstract RU/EN, related research areas, featured flag и citation export.

Фильтры: год, тип результата, исследовательское направление и язык. Сортировка по умолчанию — новые работы сначала.

Метрики показываются отдельно для Scopus, Web of Science, Google Scholar и РИНЦ. У каждой метрики есть название базы, значение, дата обновления и ссылка на профиль. Значения не суммируются между базами.

## 10. Формы и процессы

Форма сотрудничества собирает: имя, организация, роль, email, тип проекта, краткое описание, ожидаемый результат, аудитория, язык, сроки, бюджетный диапазон и согласие на обработку данных.

После отправки: подтверждение получения → ручная оценка → запрос дополнительных материалов при необходимости → встреча → письменное предложение.

Публичная форма не принимает рукописи, персональные данные участников исследования и конфиденциальные массивы данных. Передача таких материалов происходит после согласования защищённого канала.
