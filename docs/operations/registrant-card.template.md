## 3. Чек-лист опций при покупке доменов

| Опция у регистратора | Решение | Почему |
|---|:---:|---|
| **Whois Privacy (Whois zaščita)** | **ДА (ВКЛЮЧИТЬ)** | Скрывает личный телефон и адрес от спамеров. Бесплатно у Neoserv. |
| **Срок регистрации (Duration)** | **1 год** | Промо-тариф первого года (11,47 € без НДС / 13,99 € с НДС). Продление через год. |
| **Веб-хостинг (Gostovanje / Hosting)** | **НЕТ (ПРОПУСТИТЬ)** | Сайты размещены на GitHub Pages / Cloudflare (бесплатно, быстрый global CDN). |
| **Платный SSL-сертификат** | **НЕТ (ПРОПУСТИТЬ)** | Выдаётся автоматически и бесплатно через Let's Encrypt / GitHub Pages. |
| **DNS-хостинг (Brezplačno DNS gostovanje)** | **БЕСПЛАТНЫЙ (АКТИВИРОВАТЬ)** | Включается в панели Neoserv в 1 клик (`Vklopi DNS gostovanje`). |
