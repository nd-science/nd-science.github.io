## 3. Чек-лист опций при покупке доменов

| Опция у регистратора | Решение | Почему |
|---|:---:|---|
| **Whois Privacy (Whois zaščita)** | **ДА (ВКЛЮЧИТЬ)** | Скрывает личный телефон и адрес от спамеров. Бесплатно. |
| **Срок регистрации (Duration)** | **1 год** | Промо-тариф первого года (13,99 €). Продление через год. |
| **Веб-хостинг (Gostovanje / Hosting)** | **НЕТ (ПРОПУСТИТЬ)** | Сайты размещены на GitHub Pages / Cloudflare (бесплатно, быстрый CDN). |
| **Платный SSL-сертификат** | **НЕТ (ПРОПУСТИТЬ)** | Выдаётся автоматически и бесплатно через Let's Encrypt. |
| **DNS-хостинг** | **БЕСПЛАТНЫЙ** | Стандартные DNS Neoserv / Cloudflare. |
