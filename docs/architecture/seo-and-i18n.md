# SEO, GEO и локализация

## Маршруты

- Русский: `/ru/`.
- Английский: `/en/`.
- `/` перенаправляет на `/ru/`.
- Для каждой пары страниц обязательны canonical, `hreflang=ru`, `hreflang=en` и `x-default`.

## Перед публичным запуском

- Указать реальные `PUBLIC_SITE_URL` отдельно для каждого приложения.
- Проверить заголовки, description, Open Graph и структурированные данные.
- Создать уникальные страницы политики конфиденциальности и юридических сведений.
- Подключить Google Search Console, Bing Webmaster Tools и Яндекс Вебмастер после подтверждения владения доменом.
- Разрешить индексацию только после проверки всех утверждений.

## GEO

- Давать ясные ответы на реальные вопросы аудитории.
- Указывать автора, дату обновления и первичные источники там, где это уместно.
- Поддерживать согласованность RU/EN-версий.
- Не генерировать массовый контент и не подменять экспертную проверку автоматической редактурой.
