# ADR-0002: публикация и статус контента

Статус: принято 2026-10-20.

- Первичная цель — обычный статический веб-хостинг на двух отдельных доменах.
- Адаптация под OpenAI Sites выполняется после утверждения прототипов и контента.
- Пока `PUBLIC_SITE_STATUS` не равен `public`, страницы получают `noindex, nofollow`, robots.txt закрывает обход, а sitemap не создаётся.
- Переключение в `public` допускается только после release checklist.
- Хостинг, домены, DNS, аналитика и Search Console в рамках инициализации не меняются.
