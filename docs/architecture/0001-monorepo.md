# ADR-0001: один репозиторий, два приложения

Статус: принято 2026-10-20.

## Решение

Использовать pnpm workspace в `D:\Projects\Natali` с приложениями `apps/wellness` и `apps/science` на Astro 6.4.8. Эта версия выбрана вместо Astro 7, потому что Windows Application Control на рабочей станции блокирует нативный compiler binding Astro 7; Astro 6 использует официальный WebAssembly-компилятор и не требует обхода политики безопасности.

Общими являются только технические компоненты, SEO-функции и проверенный профиль. Контент, маршруты, конфигурация домена и выпуск каждого приложения независимы.

## Причины

- Одна экспертная личность и общая поддержка агентами.
- Разные аудитории, позиционирование и поисковые намерения.
- Возможность публиковать и обновлять сайты независимо.
- Меньше дублирования компонентов и проверок.
