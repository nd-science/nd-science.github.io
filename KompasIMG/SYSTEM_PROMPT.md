# СИСТЕМНЫЙ ПРОМПТ: Извлечение карточек из инфографики

## Цель
Извлечение отдельных карточек персонажей, поворотов и дополнительных элементов из двух инфографических изображений (Компас-Наставник и Компас-Исследователь) в формате PNG с прозрачным фоном.

## Ошибки, которые были допущены

### 1. Повороты обрезаны (Вид спереди и 3/4 вид)
- **Причина**: Алгоритм кластеризации нашёл перекрывающиеся кластеры из-за малых зазоров между поворотами
- **Исправление**: Использовать правильные координаты: x=30-180, x=196-310, x=340-418, x=444-558

### 2. Текстless версии сломаны (ПЕРВАЯ ПОПЫТКА)
- **Причина**: Применена единая высота обрезки y=210 ко всем картам
- **Проблема**: Разные карты имеют разную высоту:
  - Наставник Row 1: 182px, Row 2: 190px
  - Исследователь Row 1: 213px, Row 2: 194px
- **Исправление**: Карточки НЕ содержат текст - текст в отдельных регионах. Текстless = копия оригинала.

### 3. Прозрачные версии сломаны (ПЕРВАЯ ПОПЫТКА)
- **Причина**: Простое пороговое удаление фона (threshold=240)
- **Проблема**: Белые элементы (кроссовки, лицо) удаляются вместе с фоном
- **Исправление**: Использовать flood-fill алгоритм с учётом углов изображения

## Правила работы

### Всегда
1. Сначала исследовать исходные файлы (размеры, структуру, плотность пикселей)
2. Определить точные координаты для каждого элемента
3. Проверить результат визуально

### Нельзя
1. Применять единые координаты ко всем элементам
2. Использовать простое пороговое удаление фона
3. Изменять координаты без анализа исходников

### При извлечении карточек
1. Использовать координаты из таблицы выше
2. Сохранять оригинальное качество (без масштабирования)
3. Формат: RGBA PNG

### При удалении текста
1. Карточки НЕ содержат текст - текст в отдельных регионах исходного изображения
2. Текстless версия = копия оригинальной карточки
3. Для иконок: обрезать текст под иконками (y > 64px)

### При удалении фона
1. Использовать flood-fill алгоритм (как в extract_final.py)
2. Анализировать углы изображения для определения фона
3. Применять dilation + gaussian blur для сглаживания краёв
